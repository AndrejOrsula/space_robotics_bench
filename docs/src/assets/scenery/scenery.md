# Scenery

Environmental scenery registered in the Space Robotics Bench includes terrains, facilities, and other scene elements.

![Overview](../../_graphics/assets/_collage_scenery.webp)

## Facilities

<a id="iss_gateway_scenery"></a>

#### Iss Gateway Scenery (`iss_gateway_scenery`)

![iss_gateway_scenery](../../_graphics/assets/iss_gateway_scenery.webp)

| | |
|---|---|
| **Type** | extravehicular |
| **Variant** | Dataset |
| **Domains** | orbit |
| **Sub-assets** | iss, gateway |

Set `station_template_usd_path` on `ISSGatewayScenery` to use a single static station USD while retaining static collision geometry for stable benchmark scenes. Align segment handrails with benchmark waypoint paths using `handrail_segment_specs`; `handrail_specs` is shorthand for X-axis rails.
