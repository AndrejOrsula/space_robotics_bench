# Environments

SRB environments:

- [**Manipulation**](manipulation.md) - Stationary manipulation skills and sequences in various contexts
- [**Mobile Robotics**](mobile_robotics.md) - Extraterrestrial traversal and navigation
- [**Mobile Manipulation**](mobile_manipulation.md) - Combined mobility and manipulation
- [**Digital Twins**](digital_twin.md) - Facility-inspired simulations; not validated against physical facilities

## Namespaces

These pages list the simulated Gymnasium **`srb/`** environments enumerated by `srb ls env` and `srb doc docgen`.

**`srb_real/`** contains generated ROS 2 `RealEnv` deployment interfaces for `srb real_agent`. They are not validated on physical robots and have no simulated scenario. Real-task metrics require an explicitly configured task evaluator. [Sim-to-Real Transfer](../workflows/sim_to_real.md) lists shipped IDs, generation, and registration.
