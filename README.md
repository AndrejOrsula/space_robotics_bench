**Space Robotics Bench (SRB)** provides parallel, procedurally generated and domain-randomized simulation environments and tasks built on [Isaac Sim](https://developer.nvidia.com/isaac/sim) and [Isaac Lab](https://isaac-sim.github.io/IsaacLab), with a Gymnasium API and ROS 2 (including Space ROS) interfaces.
