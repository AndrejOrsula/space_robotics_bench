**Space Robotics Bench (SRB)** provides modular environments and tasks for autonomous systems across extraterrestrial scenarios, robots, and research workflows.

Start: [System Requirements](getting_started/requirements.md) → [Installation](getting_started/install.md) → [Basic Usage](getting_started/basic_usage.md).

SRB targets Isaac Sim 6.1.0 and Isaac Lab 3.0.0; Docker is the tested installation path.

[SimForge](https://github.com/AndrejOrsula/simforge) generates scenes and assets on demand.
